Theme palette licensing declarations
Reviewed 2026-10-20

Yougori ships four optional appearance themes whose colour values are taken from
the upstream palettes below. Only the colour values are used: no upstream code,
configuration, stylesheet, image or font is copied. The values are transcribed
into src/lib/appearance.ts, where each theme also carries its upstream links and
copyright line inline.
