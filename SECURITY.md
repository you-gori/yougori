# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/you-gori/yougori/security/advisories/new).
Do not open public issues, pull requests or Discord posts for unfixed vulnerabilities.

Include the affected version or commit, the component (desktop app, CLI,
appliance agent, Personal Vault, installer or runtime), reproduction steps and
the impact you observed. Reports about the hosted Yougori service use the same
channel; its server code is not part of this repository.

## Supported versions

Security fixes are made for the latest release and the `main` branch.

## Scope

Swarm Mining bounty targets are not in scope here. Follow each bounty's
published terms and [the responsible use rules](docs/swarm-responsible-use.txt).
